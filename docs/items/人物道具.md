# 人物道具

> 收录游戏中所有消耗品类物品的详细数据。
> 数据来源：`src/data/items/consumables.ts`

---

## 分类标准属性

| 属性 | 说明 |
|------|------|
| ID | 物品唯一标识 |
| 名称 | 游戏内显示名称 |
| 类型 | `consumable`（消耗品） |
| 效果 | 使用后的即时效果（HP/MP 回复） |
| 堆叠 | 是否可在背包中堆叠 |
| 商店价格 | 各商店售价 |
| 掉落来源 | 击败敌人的掉落概率 |
