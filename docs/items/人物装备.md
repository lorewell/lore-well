# 人物装备

> 收录游戏中所有装备类物品的详细数据，按槽位分组。
> 数据来源：`src/data/items/equipment.ts`

---

## 分类标准属性

| 属性 | 说明 |
|------|------|
| ID | 物品唯一标识 |
| 名称 | 游戏内显示名称 |
| 类型 | `equipment`（装备） |
| 槽位 | 装备部位（武器/头盔/护甲/鞋子/饰品） |
| 伤害类型 | 仅武器：`physical`（物理）/ `magical`（魔法）/ `hybrid`（双修） |
| 属性加成 | 装备后提供的战斗属性加成 |
| 堆叠 | ✗ 不可堆叠（装备唯一穿戴） |
| 获取方式 | 商店购买 / 怪物掉落 / 铁匠台合成 / 任务奖励 |
