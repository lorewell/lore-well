# 任务道具

> 收录游戏中所有任务类物品的详细数据。
> 数据来源：`src/data/items/quest_items.ts`

---

## 分类标准属性

| 属性 | 说明 |
|------|------|
| ID | 物品唯一标识 |
| 名称 | 游戏内显示名称 |
| 类型 | `quest`（任务道具） |
| 堆叠 | 不可堆叠（唯一获取） |
| 关联任务 | 涉及的任务 ID 与名称 |
| 获取方式 | 如何获得该物品 |
| 用途 | 在任务中的作用 |
