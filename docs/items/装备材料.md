# 装备材料

> 收录游戏中所有合成材料类物品的详细数据。
> 数据来源：`src/data/items/materials.ts`

---

## 分类标准属性

| 属性 | 说明 |
|------|------|
| ID | 物品唯一标识 |
| 名称 | 游戏内显示名称 |
| 类型 | `material`（材料） |
| 堆叠 | 是否可在背包中堆叠 |
| 掉落来源 | 击败敌人的掉落概率与数量 |
| 用途 | 可用于合成哪些装备 / 提交哪些任务 |
