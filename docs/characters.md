| 属性 | 每级增长 |

## NPC 人物

### 隐秘瀑布

```
位置：落瀑村·隐秘瀑布（village_waterfall 节点）
ID：waterfall
```

**背景**
一道从山间石缝倾泻而下的银白瀑布，水声如鼓，雾气弥漫。这里是长老艾尔文发现昏迷旅行者的地方。凝视瀑布，玩家可以触发破碎的记忆片段——黑色的尖塔、漫天战火和模糊的面孔。

**对话分支**

| 选项 | 效果 |
|------|------|
| 凝视瀑布，尝试回忆 | 触发记忆碎片节点 |
| 没事了 | 关闭对话 |

### 老板娘 玛格

```
位置：落瀑村·暮光客栈（village_inn 节点）
ID：innkeeper
```

**背景**
暮光客栈的经营者，是落瀑村中最消息灵通的人物之一。为人热情，总能给旅行者提供信息和休憩之所。她对村子近来的异常深感不安，但仍尽力维持客栈的日常运转。

**基础信息**

| 属性 | 内容 |
|------|------|
| 称呼 | 老板娘 玛格（Marg） |
| 职业 | 客栈经营者 |
| 所在地 | 落瀑村·暮光客栈 |
| 可交互 | 是（对话 + 休息 + 商店） |

**对话分支**

| 选项 | 效果 |
|------|------|
| 我想休息 | 立即回复玩家全部 HP / MP |
| 我想买些物资 | 打开客栈小卖部（生命药水等） |
| 最近有什么消息吗？ | 揭露矿洞异常和神殿奇光 |
| 没事了 | 关闭对话 |

### 铁匠 托尔

```
位置：落瀑村·铁匠铺（village_blacksmith 节点）
ID：blacksmith
```

**背景**
村中唯一的铁匠，擅长打造武器和护甲。性格直来直往，不爱与外人多话。他需要铁矿石才能为玩家打造装备，是铁匠委托任务的委托人，也是武器装备的主要商店来源。

**基础信息**

| 属性 | 内容 |
|------|------|
| 称呼 | 铁匠 托尔（Thor） |
| 职业 | 铁匠、装备锻造师 |
| 所在地 | 落瀑村·铁匠铺 |
| 可交互 | 是（对话 + 商店 + 合成） |

**对话分支**

| 选项 | 效果 |
|------|------|
| 我想看看你的商品 | 打开铁匠铺（武器/护甲/饰品） |
| 我想合成装备 | 打开合成界面（材料 + 金币换取合成装备） |
| 我有铁矿石 | 进入铸造对话（任务相关） |
| 没事了 | 关闭对话 |

**触发事件**（首次对话）
- 激活任务：**铁匠委托**（`quest_blacksmith`）

### 猎人 托比

```

ID：npc_hunter_toby
```

**背景**
经验老到的猎人，是锈齿矿道木牌上神秘「T」的留字者。三个月前他察觉怪物开始朝矿洞方向异常聚集，随即与两名同伴进入矿洞查探。深入至矿壁深坑后遭遇袭击，同伴折损，托比在深坑壁龛中独自困守近两周。妻子诺拉和儿子凯恩守在营地，最终凯恩带领玩家找回了他。

**基础信息**

| 属性 | 内容 |
|------|------|
| 称呼 | 猎人 托比（Toby） |
| 职业 | 猎人，做了十四年 |
| 所在地 | 幽暗森林·矿壁深坑 |
| 家人 | 妻子诺拉、儿子凯恩 |
| 可交互 | 是（任务关键 NPC，玩家在矿壁深坑找到） |

**对话分支**

| 选项 | 效果 |
|------|------|
| 是的，你妻子请我来找你。 | 进入父子重逢节点，托比讲述矿坑遭遇 |

| 那个蓝光是什么？ | 托比解释蓝光的幻觉效果与铁器克制方法 |

| 矿道木牌上的"T"是你写的？ | 托比追述三个月前察觉异变的经过 |

**触发事件**（对话后）
- 完成任务目标：**找到猎人托比**（`find_toby`，`quest_hunter_companion` 第三步）

### 诺拉（猎人妻子）

```
位置：幽暗森林·猎人营地（space_ruined_camp 节点）
ID：npc_hunter_wife
```

**背景**
猎人托比之妻，与丈夫和儿子凯恩常年居于幽暗森林营地，这片林子是她的家。托比进矿洞已逾三周未归，她独自守着营地，暗中承担着无法言说的担忧，却始终没有崩溃——直到玩家出现。她不是软弱的人，只是累了太久。

**基础信息**

| 属性 | 内容 |
|------|------|
| 称呼 | 诺拉（Nora） |
| 职业 | — |
| 所在地 | 幽暗森林·猎人营地 |
| 家人 | 丈夫托比、儿子凯恩 |
| 可交互 | 是（对话 + 触发支线 + 任务完结奖励） |

**对话分支**

| 选项 | 效果 |
|------|------|
| 是的，我路过这里。 | 引出丈夫失踪背景 |
| 我在找叫托比的猎人。 | 直接进入委托节点 |
| 你一个人住在这里？ | 介绍凯恩，再引到丈夫话题 |

**触发事件**（首次打开对话时自动触发）
- 激活任务：**同伴的下落**（`quest_hunter_companion`）

**任务完结**（托比找回后再次对话）
- 完成任务最终目标（`return_to_camp`）
- 给予奖励：**高级药剂 ×2**（托比存在营地的谢礼）

### 凯恩（猎人之子）

```
位置：幽暗森林·猎人营地（space_ruined_camp 节点）
ID：npc_hunter_son
```

**背景**
猎人托比与诺拉之子，今年十四岁，生于林中，在幽暗森林长大。熟悉灰烬谷口到矿道入口每一段的地形，通晓追踪之术，能辨认父亲在矿道墙壁上留下的三角刻记。父亲失踪后，他每天独自研究那张简图，等待一个有实力的旅人——然后要求同行。

他倔强、骄傲，说话直来直去，用冷淡掩盖内心的慌乱。在父亲被找回的那一刻，他叫了一声「爸」，声音是颤的。

**基础信息**

| 属性 | 内容 |
|------|------|
| 称呼 | 凯恩（Kain） |
| 职业 | — |
| 所在地 | 幽暗森林·猎人营地 |
| 家人 | 父亲托比、母亲诺拉 |
| 可交互 | 是（对话 + 加入队伍 + 完成任务目标） |

**对话分支**

| 选项 | 效果 |
|------|------|
| 你父亲的事，你妈刚跟我说了。 | 进入"要求同行"节点 |
| 你叫什么名字？ | 自我介绍，再问矿洞 |
| 你在做什么？ | 谈磨刀与矿道蜘蛛，引出父亲话题 |
| 带我一起去。 | 凯恩正式提出同行，进入"确认加入"分支 |
| 矿洞很危险，你确定吗？ | 凯恩表明决心（「待在这里更难熬」） |
| 你母亲同意吗？ | 凯恩当场求得诺拉同意 |
| 好，一起去。 | 凯恩加入，讲解父亲留下的三角标记追踪方法 |

**触发事件**（与凯恩对话后）
- 完成任务目标：**凯恩加入队伍**（`join_kain`，`quest_hunter_companion` 第一步）
