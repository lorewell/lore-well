## 子地图节点系统

每个大地点内部由多个**子地图节点**（SubLocation）组成，通过小地图界面可在节点间移动。

| 术语 | 说明 |
|------|------|
| `startNodeId` | 进入大地点时的默认起始节点 |
| 节点出口（`exits`） | 跨大地点传送，只在边界节点设置 |
| 节点方向（`north/south/east/west`） | 在大地点内相邻节点之间的导航 |
| 节点交互（`interactions`） | 战斗、NPC 对话、商店、拾取物品等 |

节点在 HUD 小地图中以**圆点**显示，当前节点高亮为紫色，可直接点击移动。

```
ID：village
startNodeId：village_center
描述：坐落于隐秘瀑布脚下的宁静村庄，世代哺育着这里的居民。
```

### 子地图节点布局

```
                    [village_waterfall]
                      （隐秘瀑布）
                           │南
[village_chief_home]──东──[village_elder_home]──东──[village_outskirts]
   （村长之屋）              （艾尔文的家）              （村子外围）
                           │南
[village_inn]────东───[village_center]────东───[village_blacksmith]
（暮光客栈）          （中心广场 ← startNode）        （铁匠铺）
                           │南                        │南
                    [village_south_gate]         [village_grocer]
                       （村南路口）                  （杂货铺）
                           │南
                    [village_portal]
                       （废旧传送阵）
```

### 节点详情

| 节点 ID | 节点名称 | 方向连接 | 主要交互 |
|---------|---------|---------|---------|
| `village_center` | 中心广场 | N→艾尔文家 W→客栈 E→铁匠铺 S→南路口 | 景物：古老石井、告示板 |
| `village_waterfall` | 隐秘瀑布 | S→艾尔文家 | NPC：凝视瀑布（记忆触发）、在水池沐浴（回复HP/MP）、探查水底（获得戒指） |
| `village_elder_home` | 艾尔文的家 | N→瀑布 W→村长之屋 E→村子外围 S→中心广场 | NPC：长老艾尔文；景物：旧书架 |
| `village_chief_home` | 村长之屋 | E→艾尔文家 | NPC：村长格雷；景物：墙上地图 |
| `village_outskirts` | 村子外围 | W→艾尔文家 | 战斗：哥布林；景物：破损栅栏 |
| `village_inn` | 暮光客栈 | E→中心广场 | NPC：老板娘玛格（休息/商店）、小莉娜；景物：壁炉 |
| `village_blacksmith` | 铁匠铺 | W→中心广场 S→杂货铺 | NPC：铁匠托尔（商店/合成）；景物：铁砧 |
| `village_grocer` | 杂货铺 | N→铁匠铺 | NPC：杂货商梅娜（商店）；景物：草药架 |
| `village_south_gate` | 村南路口 | N→中心广场 S→传送阵 | 景物：风化路牌；**出口：幽暗森林 / 古代神殿遗迹** |
| `village_portal` | 废旧传送阵 | N→村南路口 | 互动：废旧传送阵（已损坏，无法使用） |

**难度参考**：起始区域，战斗仅限村子外围的哥布林（LV 1）

## 幽暗森林

```
ID：forest
startNodeId：ash_valley_gate
描述：树冠将天光隔绝，终年弥漫着腐叶与霉苔的气息。向北可以深入幽魂古林，向东则通往废弃矿洞。
```

> 幽暗森林包含原「幽暗森林」、「森林深处」、「废弃矿洞」三区域，现作为统一子地图的 9 个节点存在。

### 子地图节点布局

```
             [ghost_grove]
             （幽魂古林）
                  │南
     [broken_moon_altar]──东──[misty_forest_path]
         （碎月祭台）               （乌雾林道）
                                       │南
                                  [ruined_camp]
                                  （猎人营地）
                                       │南
[bone_marsh]──东──[ash_valley_gate]──东──[rusty_mine_road]──东──[dark_vein_wall]
  （折骨沼）     （灰烬谷口 ← startNode）   （锈齿矿道）          （黑脉矿壁）
                    （→落瀑村）                 │北
                                          [mine_pit]
                                         （矿壁深坑）
```

### 节点详情

| 节点 ID | 节点名称 | 方向连接 | 主要交互 |
|---------|---------|---------|---------|
| `ash_valley_gate` | 灰烬谷口 | N→残营废地 E→锈齿矿道 W→折骨沼 | 战斗：哥布林巡逻队；景物：烧焦的路牌；**出口：落瀑村** |
| `bone_marsh` | 折骨沼 | E→灰烬谷口 | 战斗：伏击的哥布林；拾取：泥中的行囊（生命药水） |
| `ruined_camp` | 猎人营地 | S→灰烬谷口 N→乌雾林道 | NPC：**诺拉**（触发支线）；NPC：**凯恩**（加入队伍）；景物：猎人离家前的笔记 |
| `misty_forest_path` | 乌雾林道 | S→残营废地 W→碎月祭台 | 战斗：缠绕的狼灵；景物：刻字的界石 |
| `broken_moon_altar` | 碎月祭台 | E→乌雾林道 N→幽魂古林 | 战斗：石像鬼守卫；拾取：祭台铁匣（古代钥匙） |
| `ghost_grove` | 幽魂古林 | S→碎月祭台 | 战斗：狼灵首领、远古石像鬼；景物：符文古树 |
| `rusty_mine_road` | 锈齿矿道 | W→灰烬谷口 E→黑脉矿壁 N→矿壁深坑 | 战斗：守道蜘蛛；景物：警示木牌（背面刻有"T"） |
| `mine_pit` | 矿壁深坑 | S→锈齿矿道 | 战斗：挖坑的哥布林、巨蛛；NPC：**猎人 托比**（受困，任务关键）；⚠️ 任务目标节点 |
| `dark_vein_wall` | 黑脉矿壁 | W→锈齿矿道 | 战斗：守矿哥布林；拾取：裸露的矿脉（铁矿石） |

### 难度参考

| 区域 | 建议等级 | 主要威胁 |
|------|---------|---------|
| 灰烬谷口 / 折骨沼 | LV 2–3 | 哥布林 |
| 猎人营地 / 乌雾林道 | LV 3–4 | 森林狼 |
| 碎月祭台 / 幽魂古林 | LV 5+ | 石像鬼（HP150/ATK25/DEF20） |
| 锈齿矿道 / 矿壁深坑 | LV 3–4 | 洞穴蜘蛛（SPD18，先手优势强） |
| 黑脉矿壁 | LV 3–4 | 哥布林 + 铁矿石掉落（铁匠委托核心） |

### 任务关联

| 节点 | 关联任务 |
|------|---------|
| `ruined_camp` | **同伴的下落**（`quest_hunter_companion`）— 猎人托比委托触发点 |
| `mine_pit` | **同伴的下落** — 第二步目标：抵达矿壁深坑 |
| `dark_vein_wall` | **铁匠的请托**（`quest_blacksmith`）— 铁矿石来源 |
| `broken_moon_altar` | **长老的委托**（`quest_elder`）— 古代钥匙获取点 |
