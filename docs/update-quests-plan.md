## 概述

将「残营废地」（`space_ruined_camp`）节点全面翻新，围绕猎人一家三口重写剧情，替换原有"托比受伤困在营地 + 腕环"的设计。

## 新增 NPC

### C. 诺拉（Nora）— 猎人妻子（`npc_hunter_wife`）

- **位置**：`space_ruined_camp`（猎人营地）
- **角色背景**：与丈夫托比在幽暗森林中生活多年，持家有道。丈夫几周前和同伴进矿洞调查异变，再未归来。她日夜担忧，独自撑起营地和年幼的儿子
- **核心作用**：`quest_hunter_companion` 的新委托人，取代原托比（受伤困在营地）的设定
- **对话节点**：`greeting → request_help → pray_blessing`
- **重写文件**：`src/data/dialogues/hunter.ts`

### D. 凯恩（Kain）— 猎人儿子（`npc_hunter_son`）

- **位置**：`space_ruined_camp`（猎人营地）
- **角色背景**：托比与诺拉的儿子，从小在森林中长大，熟悉林间小路和野兽踪迹，会追踪术。对父亲的失踪既担心又倔强，渴望证明自己不是小孩
- **核心作用**：主动要求加入玩家队伍协助寻找父亲；加入后作为临时队友，具备追踪定位能力
- **对话节点**：`greeting → insist_join → join_party`
- **重写文件**：`src/data/dialogues/hunter.ts`

## 剧情流程

1. 玩家进入猎人营地，与**诺拉**（猎人妻子）对话（`greeting`），得知丈夫托比和同伴几周前进矿洞调查异变，至今未归。她恳请玩家帮忙寻找
2. 玩家接受委托 → 触发重制版 `quest_hunter_companion`
3. 此时**凯恩**（猎人儿子）突然插话（`insist_join`）——"让我跟你一起去！我熟悉这片林子，会追踪术，能更快找到父亲！"
4. 诺拉起初反对（"你还太小"），凯恩反驳说自己比任何外人都了解森林。诺拉无奈同意，含泪叮嘱二人平安归来（`pray_blessing`）
5. **凯恩加入玩家队伍**，成为临时队友（战斗辅助 + 追踪定位功能）
6. 在矿洞深处找到受伤的托比，父子重逢（`reunion`）
7. 一同返回营地，诺拉喜极而泣。凯恩解锁成长型对话线；托比给予谢礼

## 设计决策

| 决策 | 理由 |
|------|------|
| 猎人营地由废变活 | 原"残营废地（狼群出没 + 单人被困）"扩展为"猎人家庭居住 + 父子分离 + 凯恩同行"，大幅增加情感厚度和代入感 |
| 儿子加入队伍替代腕环信物 | 腕环是死物，凯恩是活人——活人队友提供追踪能力、父子重逢戏码和后续成长线，叙事价值远高于信物 |
